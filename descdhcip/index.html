DHCIP, dilihat dari lapisan API dan data

DHCIP (Damri Human Capital Intelligence Platform) adalah dashboard performa karyawan DAMRI — KPI, penilaian 360°, Nine Box Matrix, dan rekomendasi AI dalam satu platform. Halaman ini merangkum bagian yang saya bangun: API PHP CodeIgniter yang melayani keempat modul dashboard, skema database di baliknya, dan integrasi Gemini API untuk menghasilkan rekomendasi otomatis.

02Kontribusi

Mock Endpoint yang saya rancang

Sebagian rute inti yang melayani keempat modul dashboard, dari agregasi KPI sampai pemicu rekomendasi AI.

GET/api/v1/dashboard/summary
Agregasi KPI lintas unit kerja untuk tampilan dashboard utama.
GET/api/v1/employees/{id}
Profil kinerja individu — KPI, akhlak, dan kehadiran.
GET/penilaian360/{id_pegawai_dinilai}
Kumpulan penilaian 360° dari rekan, atasan, dan bawahan, lengkap dengan rata-rata skor.
GET/api/v1/nine-box?level=division
Pemetaan performa vs potensi pada level karyawan, leader, atau divisi.
POST/api/v1/ai/recommendations/generate
Memicu Gemini Flash 2.5 untuk menyusun rekomendasi perbaikan per karyawan.
03Arsitektur

Bagaimana data mengalir

Dashboard frontend memanggil API, API membaca/menulis ke MySQL, dan memanggil Gemini API saat rekomendasi diminta.

Alur permintaan → agregasi data → (opsional) generasi rekomendasi → simpan

04Integrasi AI

Jalur rekomendasi otomatis

Empat langkah dari data mentah sampai rekomendasi tersimpan.

1

Kumpulkan data kinerja

Backend menggabungkan KPI, akhlak, kehadiran, dan penilaian 360° satu karyawan menjadi satu payload.

2

Susun prompt terstruktur

Payload diformat menjadi konteks yang dikirim ke Gemini Flash 2.5 lewat Gemini API.

3

Ambil rekomendasi

Respons model diparsing dan divalidasi sebelum ditampilkan ke pengguna dashboard.

4

Simpan histori

Rekomendasi disimpan ke MySQL agar bisa dilacak dan dibandingkan antar periode.

06Sorotan

Yang saya bawa ke tim

4 modul, 1 API

Penilaian 360°

Data konsisten
